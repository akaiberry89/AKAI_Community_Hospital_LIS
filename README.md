## 🔬 Project Overview
AKAI Community Hospital LIS is an enterprise-grade informatics portfolio mapping the end-to-end lifecycle of clinical laboratory data. Leveraging 10 years of professional laboratory experience, this project simulates the integration of clinical analyzer outputs, relational database architecture, HL7/FHIR interoperability with Epic EHR systems, HIPAA compliance frameworks, and Power BI operational dashboards.

---

## 🗺️ Academic Roadmap & Modular Build Timeline

### 🧠 Phase 1: Logic & System Scoping (Fall 2026)
*   **Associated Classes:** INFM 109 (Informatics Fundamentals) & SDEV 120 (Logic & Problem Solving)
*   **Focus:** Define the technical scope of the LIS middleware, map high-level specimen workflows, and design programmatic logic loops for sample intake validation.

### 🗂️ Phase 2: Relational Database Architecture (Spring/Summer 2027)
*   **Associated Classes:** DBMS 110 (SQL & Data Modeling) & HIMT 102 (Healthcare Data Structure)
*   **Focus:** Engineer the PostgreSQL relational database schema. Build optimized tables using constraints, primary keys, and foreign keys for:
    *   `Specimens` (Accessioning, collection data, and storage tracking)
    *   `Test_Catalog` (LOINC coding integration for clinical tests)
    *   `Lab_Results` (Analyte values, normal/critical flag status, and technologist validation)

### 🔀 Phase 3: Interoperability & Clinical Workflows (Spring 2028)
*   **Associated Classes:** HIMT 106 (Healthcare Informatics) & CPIN 269 (Project Management)
*   **Focus:** Document the HL7 messaging pipeline connecting the LIS database to a simulated Epic EHR interface, focusing on `ORM^O01` (Order Messages) and `ORU^R01` (Result Observations).

### 🔐 Phase 4: Cybersecurity & HIPAA Compliance (Summer 2028)
*   **Associated Classes:** CSIA 105 (Cybersecurity) & HIMT 104 (HIPAA & Healthcare Law)
*   **Focus:** Establish robust Role-Based Access Controls (RBAC), data encryption protocols at rest/in transit, and complete immutable audit logging schemas complying with CLIA and HIPAA Security Rules.

### 📊 Phase 5: Power BI Analytics & Capstone Delivery (Fall 2028)
*   **Associated Classes:** INFM 219 (Power BI & Analytics) & CPIN 279 (IT Capstone)
*   **Focus:** Inject mock datasets into Power BI and draft DAX formulas to build executive dashboards tracking laboratory Turnaround Time (TAT) and Critical Value Notification metrics.
